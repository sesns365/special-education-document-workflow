# 特教公文工作流

這是一個可分享給其他教師使用的 Codex 專案技能，提供特教公文的「專案初始化」、「開工」、「收工」與「歸檔」固定流程。

本 Repository 只保存工作流規則與技能檔，不保存任何學校公文、學生資料或個人資料。

Repository：<https://github.com/sesns365/special-education-document-workflow>

## 重要安全提醒

⚠️ 請不要把機密文件放入 GitHub。

以下內容應留在學校核准的本機或私有儲存位置，另行管理，不得上傳到這個公開 Repository：

- 原始公文 PDF、ZIP、DOCX、XLSX、PPTX 或掃描檔。
- 學生姓名、個案代碼與鑑定、診斷、障礙類別資料。
- 身分證字號、地址、電話、家庭資料、醫療或社福資料。
- 公文附件、名冊、申請表、服務紀錄、每日處理紀錄及待辦案件內容。
- 密碼、API 金鑰、Token、Cookie、憑證及其他登入資訊。

這個 Repository 的 .gitignore 只是降低誤上傳機率，不是機密資料保護措施。每次提交前仍應檢查：

~~~text
git status --short
git diff --cached --stat
~~~

若不小心上傳機密資料，不能只在最新版本刪除檔案就視為安全。應立即停止分享、撤銷或更換已暴露的密碼／Token，通知學校或資料管理者，並另行處理 Git 歷史中的敏感內容。

## 下載與安裝

### 下載 ZIP

1. 開啟本 Repository。
2. 選擇 Code → Download ZIP。
3. 解壓到一般工作位置，不要解壓到含有機密公文的公開 Git Repository。
4. 將下列檔案複製到自己的「私有專案資料夾」：

~~~text
特教公文工作流使用說明書.md
.agents/skills/special-education-document-workflow/
~~~

5. 在私有專案資料夾建立下列本機資料夾：

~~~text
00原始公文備份
01待辦公文
02已完成待歸檔
03歸檔公文
90_每日處理紀錄
99_系統紀錄
~~~

6. 從專案根目錄開啟 Codex 對話，輸入「專案初始化」。

### 使用 Git Clone

~~~text
git clone https://github.com/sesns365/special-education-document-workflow.git
~~~

下載後仍要把實際公文放在私有本機資料夾，不要放入公開 Repository，也不要把含公文的資料夾直接推送到 GitHub。

## 固定指令

### 專案初始化

檢查工作流說明書、技能、資料夾與目前案件狀態，不搬移、不改名、不刪除文件。

### 開工

掃描 00原始公文備份中的新 PDF／ZIP，保留原始檔，讀取及分析內容，並初步分類至：

- 00轉知公文：只需轉知或存查；單純轉知研習資訊歸此類。
- 01業務處理：需要回覆、填報、送件、核示、經費處理，或需要報名、派員、核准、繳費、回報的研習。
- 02申請服務：申請特教相關專業人力、專業服務、學生服務、服務需求或其他資源。
- 99待分類：資料不足或無法確認主要辦理方向。

開工後會建立案件分析資料，並產生當日待辦公文總表，依期限、研習日期與處理優先順序排列。

### 收工

更新 01待辦公文內未完成案件的狀態、下一步、期限提醒與每日處理紀錄。不會自動把案件搬走。

### 歸檔

只有明確輸入「歸檔」才會處理 02已完成待歸檔。完成案件會依原始收文日期存入 03歸檔公文 的民國年月資料夾，例如 11508，並命名為：

~~~text
收文日期_公文名稱(日期止／研習日期)
~~~

原始 PDF／ZIP 仍保留在本機的 00原始公文備份。歸檔不會覆蓋同名檔案，也不會猜測缺少的收文日期。

## 本機資料與公開 Repository 的分離

建議採用下列方式：

- 公開 GitHub Repository：只放工作流技能、說明書與 README。
- 學校私有資料夾：放原始公文、待辦案件、已完成案件與歸檔資料。
- 每次更新技能時，只將不含機密資料的規則檔提交到 GitHub。
- 不要把整個含有公文的學校資料夾直接執行 git add -A。

若要更新工作流，修改下列檔案後再檢查差異：

~~~text
特教公文工作流使用說明書.md
.agents/skills/special-education-document-workflow/SKILL.md
.agents/skills/special-education-document-workflow/agents/openai.yaml
README.md
~~~

## 注意事項

本專案提供的是 Codex 的工作流規則，不會取代承辦人核對原始公文、判斷期限、正式簽辦或確認個案服務。涉及學生或其他敏感資料時，應遵守學校個資與資訊安全規範。
